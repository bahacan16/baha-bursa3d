# Nilüfer Walk

Bursa / Nilüfer / 29 Ekim Mahallesi / 502. Sokak merkezli, 2 km çaplı bir alanda tarayıcıda (masaüstü ve mobil) oynanan, üçüncü şahıs yürüyüşlü 3D simülasyon.

> Geliştirme sürüyor — ayrıntılı kullanım bu dosyaya fazlar ilerledikçe eklenecek.

## Geliştirme

```bash
npm install
npm run dev        # http://localhost:5173
npm run test       # birim testleri (Vitest)
npm run test:e2e   # duman testi (Playwright)
npm run build
```
